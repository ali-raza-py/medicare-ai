# MedCare AI — Team Boundaries
**OWNER: SHARED — Ali Raza + Shabbar Raza**

## One product
There must be:
- One repository
- One architecture
- One source of truth

Do NOT build two independent apps.

## Shabbar owns
Frontend implementation, UI/UX execution, frontend API wiring, responsive testing and UI bug fixing.

## Ali owns
Architecture, backend/core engineering, AI/RAG, evidence grounding, database/data architecture, integration, security/safety and final demo direction.

## Shared
- Review each other's work.
- Report blockers early.
- Test before calling work complete.
- Use synthetic/de-identified medical demo data.
- Protect user privacy.
- Never commit secrets.
- Coordinate before changing architecture or shared interfaces.

## Critical communication rule
Before frontend/backend API contracts are changed, communicate the change to the other owner.
